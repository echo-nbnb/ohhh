# 交互设计文档

## 概述

寻麓千年色是**摄像头 + 手势驱动**的五幕沉浸式交互装置。用户无需触摸屏幕，全程通过手部动作与投影画面交互。

## 手势定义

| 手势 | 识别方式 | 作用 |
|------|---------|------|
| ✊ 握拳 | 四指指尖 y > MCP y（全部弯曲） | 确认颜色 / 提交绘画 / 重启择色 |
| ☝️ 食指伸出 | 仅食指指尖 y < MCP y - 0.05，其余弯曲 | 进入绘画模式 / 录制轨迹 |
| 🖐️ 张手 | 四指指尖 y < MCP y - 0.05（全部伸展） | 取消当前操作 / 返回 |

手势防抖：1 帧确认（展览环境可调至 3 帧）。

## 手势状态机 (FSM)

```
COLOR_EXTRACTION ← 第一幕：颜色提取
    │ 握拳 → 分析物件/衣物颜色 → 自动确认
    ▼
GLOBAL ← 全局空闲
    │ 食指 → DRAWING
    │ 握拳 → 重启 COLOR_EXTRACTION
    ▼
DRAWING ← 第二幕：绘画
    │ 食指 → 录制轨迹
    │ 握拳 → CANDIDATE（识别物象→自动确认）
    │ 张手 → GLOBAL（取消）
    ▼
CANDIDATE ← 物象候选
    │ 握拳 → GLOBAL（确认物象→触发人物推荐）
    │ 张手 → DRAWING（重画）
    ▼
CHAR_RECOMMEND / CHAR_WHEEL ← 第三幕：人物选择（预留）
```

## 五幕用户旅程

### 第零幕 · 开场
- 静止底图 + 居中大标题 + 四周飘动 icon + 背景光效呼吸
- 用户点击 / 握拳 → 进入第一幕

### 第一幕 · 入境
- 彩带居中，Y 轴缓慢呼吸 + 飘动 icon
- 0-5s：邀请文字 1 + 落款
- 5s：切换邀请文字 2，落款消失
- 13s：全屏碎光散开 → 白屏 → 进入第二幕

### 第二幕 · 寻色
- 4 步自动/手动流程：
  1. "请将随身之物靠近光中" — 白盘呼吸
  2. "让我看看藏着怎样的颜色"
  3. 单色 LiquidChrome 涌入 + "一缕明黄浮出光面"
  4. 双色交融 + "明黄与深蓝相遇"
- 颜色盘 30s 持续旋转
- 后端控制 `step` + `recognizedColors`

### 第三幕 · 筑景
- 颜色条 + 标题 + 动态说明文字
- 用户食指绘画 → 握拳提交 → sketch 识别 → 物象叠加 + 说明
- 支持两轮绘画（可配 `maxRounds`）
- 后端控制 `onRecognizeSketch`

### 第四幕 · 唤灵（SpiritModule 可移植版）
- 传入 `character` 对象：`{ name, title, image, monologue, spiritLine }`
- 自动播放：寻找 → 剪影 → 台词 → 显影 → 身份揭示
- 1920×1080 舞台等比缩放

### 第四幕 · 唤灵（流程版 Act4SpiritCalling）
- 22.8s 自动播放八阶段：
  开场 → 寻找 → 加载 → 找到 → 空框 → 蓝台词 → 黄台词 → 揭示
- 人物框 + 颜色块漂浮 + 双色条
- 后端控制 `onFetchSpiritMatch`

### 第五幕 · 成笺
- 27.2s 自动播放十一帧：
  成笺 → 地点+桥 → 树 → 颜色盘+人物盘 → 标题背景 → 上方标题 →
  物象解说 → AI 文案 → 生成链路 → 盖章+日期 → 主标题+二维码
- LiquidChrome 双色液态盘 + 外周旋转
- 后端控制 `postcardData`

## 颜色系统

六色基调（HSV 匹配）：

| 颜色 | 含义 | HSV 中心 |
|------|------|---------|
| 岳麓绿 | 根脉、生长 | (60, 120, 110) |
| 书院红 | 发问、理想 | (8, 140, 110) |
| 西迁黄 | 坚韧、前行 | (28, 160, 180) |
| 湘江蓝 | 流动、包容 | (115, 130, 110) |
| 校徽金 | 荣耀、远方 | (22, 180, 200) |
| 墨色 | 求索、沉思 | (0, 5, 18) |

颜色检测流程：物件 HSV → 六色匹配 → 失败则衣物兜底 → 再失败随机选非墨色。

## 物象系统

88 物象 + QuickDraw 345 类映射。启发式预测器根据轨迹几何特征（闭合性、宽高比、方向变化）分类，颜色加权排序。识别失败时随机兜底（古树/书卷/石阶/林荫道）。

## 人物推荐

35 位湖湘历史人物，颜色+物象→参考表命中→关键词匹配→同组加权。无参考表命中时 top-15 加权随机选，避免重复。
